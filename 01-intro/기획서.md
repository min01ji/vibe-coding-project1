# 가상 인물 자기소개 웹페이지 기획서

## 1. 웹페이지의 목표

- **프로젝트명** ‘처음 만난 친구들을 위한 자기소개 웹페이지’
- **페이지 테마** 《케이온!》의 미오를 회보라색 후드의 도트 아트로 표현한 자기소개 페이지입니다.
- **누가 보나요?** 같은 수업을 듣고 처음 만난 대학생 친구들
- **친구들이 무엇을 알면 좋을까요?** 도토리의 기본 정보와 취미, 관심사를 쉽게 살펴볼 수 있도록 합니다.
- **친구들과 어떤 이야기를 나누고 싶나요?** 도토리의 취미나 관심 분야를 계기로 편하게 인사를 나눕니다.
- **제작 범위** 소개와 그림을 한 페이지에 담는 웹페이지를 만듭니다. 회원가입, 로그인, 게시판, 데이터 저장은 범위에서 제외합니다.

## 2. 소개할 가상 인물

| 항목 | 설정 |
| --- | --- |
| 별명 | 도토리 |
| 나이와 성별 | 22세 남성 |
| 전공과 학년 | 디지털콘텐츠학과 2학년 |
| 성격 | 처음에는 조용하지만 친해지면 이야기를 많이 합니다. |
| 취미 | 농구 경기 보기, 사진 찍기, 카페 탐방 |
| 관심 분야 | 웹 디자인, 영상 편집, 인공지능 |
| 좋아하는 음식 | 돈가스와 떡볶이 |
| 대학 생활 목표 | 다양한 사람을 만나고 팀 프로젝트 경험을 쌓는 것입니다. |
| 인사말 | 처음이라 조금 어색하지만 편하게 인사해 주세요! |

위 정보는 실습용으로 만든 가상 정보입니다. 실제 이름, 학번, 연락처, 이메일, 사진은 사용하지 않습니다.

## 3. 화면에 넣을 내용

| 화면 순서 | 넣을 내용 | 화면 문구 예시 |
| --- | --- | --- |
| 왼쪽 첫 부분 | 페이지 제목, 별명, 인사말 | ‘안녕하세요, 도토리입니다!’ / ‘처음이라 조금 어색하지만 편하게 인사해 주세요!’ |
| 왼쪽 기본 정보 | 학년, 전공, 성격, 대학 생활 목표 | ‘디지털콘텐츠학과 2학년입니다. 다양한 사람을 만나고 팀 프로젝트 경험을 쌓고 싶어요.’ |
| 왼쪽 취미와 관심사 | 취미, 관심 분야, 좋아하는 음식 | ‘농구 경기 보기, 사진 찍기, 카페 탐방을 좋아해요. 웹 디자인, 영상 편집, 인공지능에 관심이 있어요. 좋아하는 음식은 돈가스와 떡볶이예요.’ |
| 왼쪽 마무리 | 친구에게 전하는 한마디, 가상 인물 안내 | ‘관심사가 비슷하다면 수업에서 이야기 나눠요!’ / ‘도토리는 수업 실습을 위해 만든 가상 인물입니다.’ |
| 오른쪽 | 첨부 이미지를 바탕으로 만든 미오의 도트 아트 | 그림만 표시 |

- **분위기와 색** 흰색에 가까운 바탕과 검정 글자로 소개를 꾸미고, 그림의 배경은 투명하게 만들어 페이지 바탕색이 비치게 합니다.
- **배치** 왼쪽에 소개를 작은 글씨로 왼쪽 정렬해 한 열에 둡니다. 오른쪽의 넓은 영역을 미오 그림에 사용합니다. 좁은 화면에서는 소개 아래에 그림을 배치합니다.
- **도트 아트** 새로 첨부한 이미지 속 미오의 후드의 회보라색과 정면 구도를 살립니다. 얼굴, 머리카락과 셔츠는 흑백으로 표현합니다. 그림은 `assets/` 폴더에서 불러옵니다.
- **사용할 기술** HTML로 제목, 문단, 목록을 구성하고 CSS로 색, 글자 크기, 여백, 화면 배치를 정합니다. 첫 실습에는 JavaScript와 외부 서비스를 사용하지 않습니다.

## 4. 만드는 순서

파일 경로는 `01-intro` 폴더를 기준으로 합니다.

| 파일 | 역할 |
| --- | --- |
| `기획서.md` | 웹페이지에 담을 내용과 완료 기준을 정리합니다. |
| `index.html` | 자기소개 문구와 화면 구조를 담습니다. |
| `style.css` | 흑백 색상, 글자 크기와 화면 배치를 정합니다. |
| `assets/mio-hood-transparent.png` | 미오의 도트 아트입니다. |

1. **HTML로 내용 구성**  
   `index.html`에 상단 소개, 기본 정보, 취미와 관심사, 마무리 영역을 작성합니다. 소개를 한 열로 묶고 미오 그림을 추가합니다. 카테고리 제목은 영어로 쓰고, 소개 본문과 코드 주석은 한국어로 작성합니다.
2. **CSS로 화면 꾸미기**  
   `style.css`를 만들어 `index.html`에 연결합니다. 왼쪽에 소개 글을 작게 배치하고 오른쪽에 큰 그림을 둡니다. 카테고리 제목에는 세리프 글꼴을, 본문에는 읽기 쉬운 한글 글꼴을 사용합니다.
3. **실행 및 확인**  
   브라우저에서 `index.html`을 엽니다. 컴퓨터 화면과 스마트폰처럼 좁은 화면에서 글자와 이미지가 잘리지 않는지 확인합니다.

기능을 추가할 때는 기획서를 먼저 수정한 후 구현합니다.

## 5. 완료 기준

- [ ] `index.html`과 `style.css`가 `01-intro` 폴더에 있습니다.
- [ ] `index.html`을 열면 자기소개 화면이 오류 없이 나타나고 제목과 인사말이 보입니다.
- [ ] 별명, 학년, 전공, 성격, 취미 3개, 관심 분야 3개, 좋아하는 음식, 대학 생활 목표가 표시됩니다.
- [ ] 친구에게 전하는 한마디와 가상 인물 안내 문구가 표시됩니다.
- [ ] 넓은 화면에서 자기소개가 왼쪽에 작은 글씨로 한 열에 왼쪽 정렬되어 있습니다.
- [ ] 오른쪽에 첨부 이미지 속 후드를 쓴 미오의 도트 아트가 크게 표시되며, 후드의 회보라색과 투명 배경이 적용됩니다.
- [ ] 좁은 화면에서는 소개 아래에 그림이 표시되며, 그림은 정지 상태입니다.
- [ ] 실제 개인정보와 실제 사진이 포함되지 않습니다.
- [ ] 카테고리 제목은 영어이며, 소개 본문과 코드 주석은 한국어입니다.
- [ ] 컴퓨터와 스마트폰 화면에서 가로 스크롤 없이 읽을 수 있고 글자가 깨지거나 잘리거나 겹치지 않습니다.
- [ ] 외부 서비스나 인터넷 연결 없이 실행됩니다.
