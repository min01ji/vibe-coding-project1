# 벽돌깨기 게임 기획서

## 1. 제작 범위

브라우저에서 실행하는 1인용 벽돌깨기 게임을 자바스크립트로 만든다. 별도 설치나 인터넷 연결 없이 `brick_game.html`을 열어 실행할 수 있게 한다. 이번 작업에서는 기획서만 작성한다.

| 파일 | 역할 |
| --- | --- |
| `brick_game.html` | 게임 화면, 조작 안내, 상태 표시 |
| `brick_game.css` | 화면 배치와 색상 |
| `brick_game.js` | 키 입력, 공의 이동, 충돌, 승패 처리 |
| `assets/miku.png` | 첨부 이미지를 바탕으로 제작 단계에서 준비할 조작 캐릭터 |

모든 경로는 `myenv_vibe/02-bricks`를 기준으로 한다.

## 2. 화면과 배치

- 1024 × 768 해상도의 모니터에서 브라우저 메뉴와 주소창이 표시된 상태로도 게임판, 상태 표시, 조작 안내가 스크롤 없이 보이게 한다.
- 게임판의 기준 크기는 960 × 600px이다. 표시할 공간이 부족하면 화면에 맞춰 같은 비율로 줄인다. 아래 치수는 모두 기준 게임판에서의 값이다.
- 배경은 검정색(`#000000`), 벽돌은 미쿠의 민트색(`#39C5BB`), 공과 안내 문구는 흰색으로 표시한다.
- 벽돌은 위쪽에 7줄, 한 줄에 8개씩 배치한다. 벽돌 하나는 가로 100px × 세로 24px이며 가로와 세로 간격은 각각 8px이다.
- 화면 아래의 조작 캐릭터에는 첨부한 미쿠 이미지를 사용한다. 제작할 때 캐릭터 주변의 체크무늬와 오른쪽 위 문구를 제거한 투명 PNG를 준비한다. 캐릭터 비율을 유지하며 90 × 96px 영역 안에 표시한다.
- 공은 캐릭터 상단의 가로 80px 충돌 범위에서 튕긴다. 충돌 범위는 투명 여백을 제거한 이미지의 상단 중앙에 맞춘다.

## 3. 조작과 진행

| 상황 | 조작과 결과 |
| --- | --- |
| 시작 대기 | 공을 캐릭터 위에 정지시키고 ‘스페이스바로 시작’이라고 표시한다. |
| 시작과 이동 | 스페이스바를 한 번 누르면 공이 위쪽으로 출발한다. 좌우 방향키로 미쿠를 이동하며 게임판 밖으로 나갈 수 없다. |
| 공의 반사 | 공은 양쪽 벽, 천장, 벽돌, 미쿠의 충돌 범위에 닿으면 튕긴다. 벽돌은 한 번 맞으면 사라진다. |
| 공을 놓침 | 공이 화면 아래로 빠지면 남은 기회가 1회 줄어든다. 기회가 남으면 기존 벽돌 상태를 유지하고 스페이스바를 다시 누를 때까지 대기한다. |
| 승리와 패배 | 벽돌을 모두 없애면 ‘성공!’, 처음 주어진 3회의 기회를 모두 쓰면 ‘게임 종료’를 표시한다. |
| 재시작 | 승패가 표시된 뒤 스페이스바를 누르면 벽돌과 기회를 초기화하고 새 게임을 시작한다. |

화면에는 남은 벽돌과 남은 기회를 표시한다. 1차 제작 범위는 한 판이며 남은 벽돌 수를 진행 표시로 사용한다.

## 4. 제작 전 확인 질문

이 기획서는 아래 기본값을 기준으로 작성했다. 선호가 다르면 제작 전에 해당 항목을 수정한다.

1. **벽돌 크기** — 100px은 가로 너비로 보고 세로 24px을 정했다. 가로·세로 모두 100px을 뜻했나요? 정사각형 7줄은 간격 없이도 높이 700px이므로 한 화면에 담으려면 배율이나 배치를 다시 정해야 합니다.
2. **미쿠의 반사 위치** — 미쿠 머리 위에서 공이 튕기는 방식으로 정했다. 머리 위 대신 캐릭터 전체에 닿을 때 튕기는 방식이 더 좋나요?
3. **실패와 재도전** — 3회 기회를 주고 공을 놓칠 때마다 스페이스바로 다시 출발하도록 정했다. 한 번 놓치면 바로 끝나는 방식이 더 좋나요?

## 5. 제작 후 완료 기준

- HTML을 열면 CSS, 자바스크립트, 미쿠 이미지가 정상적으로 불러와진다.
- 1024 × 768 해상도에서 브라우저 확대율 100%로 열었을 때 게임판과 안내가 스크롤 없이 보인다.
- 검정 배경에 민트색 벽돌이 7줄 × 8개로 표시되고, 시작 전에는 공이 움직이지 않는다.
- 스페이스바로 시작하고 좌우 방향키로 미쿠를 움직일 수 있다. 미쿠가 경계를 넘지 않고 공이 각 충돌 지점에서 튕긴다.
- 벽돌 하나를 맞히면 그 벽돌이 사라지고 남은 벽돌 수가 1 줄어든다.
- 공을 놓쳤을 때 기회가 3 → 2 → 1 → 0으로 줄어드는지, 남은 기회가 있을 때 벽돌 상태가 유지되는지 확인한다.
- 마지막 벽돌을 없애거나 기회를 모두 쓰면 각각 승리와 패배가 표시되고, 스페이스바로 처음 상태의 새 게임을 시작할 수 있다.
